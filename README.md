Vanna.AI Streamlit App

1 Passo:
    Antes de clonar o repositório,vá no site do Vanna,e adquira a chave API.
    Site: https://vanna.ai/

2 Passo:
Criar um ambiente virtual
    python3 -m venv venv
3 Passo:
    source venv/bin/activate
4 Passo:
    Instalar as dependências:
        pip install -r requirements.txt
5 Passo:
    NO VSCODE,crie o arquivo "secrets.toml" dentro desta pasta ".streamlit" .Dentro do arquivo secrets.toml,coloque "API_KEY = Sua chave API".

6 Passo:
    Run
        streamlit run aplicativo.py


Espero que tenha dado certo <3,se precisar de ajuda para rodar o chatbot,entre em contato.
